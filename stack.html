工具与系统

我是如何构建的。

一套偏向快速验证、可观察和持续迭代的 AI 产品工具链。技术只是支架，目标始终是把模糊想法变成可使用的真实产品。

01 / 产品层

界面与应用

把复杂能力收进安静、清楚且可预期的产品界面。

  • Next.js + TypeScript产品外壳 / 类型系统
  • React + Tailwind CSS交互 / 设计令牌
  • Figma流程 / 原型 / 视觉系统
02 / 智能层

模型与智能体

围绕上下文、工具调用和评估搭建可靠的 Agent Harness。

  • OpenAI API推理 / 结构化输出 / 工具
  • LangGraph + MCP编排 / 连接能力
  • RAG + Evaluations上下文 / 证据 / 质量闭环
03 / 运行层

数据与交付

让实验可以被观察、部署和逐步变成稳定系统。

  • Supabase + PostgreSQL数据 / 鉴权 / 向量搜索
  • Vercel + GitHub预览 / 发布 / 协作
  • PostHog产品信号 / 行为反馈

工作原则

先验证不确定性

先验证最不确定的假设，而不是先把最容易的功能全部做完。

让状态可见

Agent 正在做什么、用了什么信息、为什么失败，都应该能够被理解。

让复杂度值得

每一层抽象都必须换来更清楚的行为、更快的迭代或更可靠的结果。
